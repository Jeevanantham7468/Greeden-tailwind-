# 🌿 Greeden - Plant Store Website

Greeden is a modern and responsive plant e-commerce website built using **HTML** and **Tailwind CSS**. The project features a clean user interface, mobile-friendly design, and showcases a variety of indoor plants, products, and services. It is designed as a front-end project to demonstrate responsive web development using Tailwind CSS.

## 🚀 Features

* 🌱 Modern and responsive landing page
* 📱 Mobile-first design
* 🎨 Built with Tailwind CSS utility classes
* 🛍️ Product showcase section
* ⭐ Customer reviews/testimonials
* 📞 Contact section
* 🔍 Clean and user-friendly navigation
* ⚡ Fast loading and lightweight

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* CSS3
